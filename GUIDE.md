# Turnly User Guide

## Getting Started

### Step 1: Enter Your Name
When you first open Turnly, you'll see a welcome screen asking for your name. This is how others will know who you are in groups.

- Enter your name (e.g., "John", "Sarah")
- Click "Let's Go"
- Your name is saved locally on your device

### Step 2: Create or Join a Group
You'll see the dashboard with two options:

#### Create a Group
Perfect if you're starting the payment rotation!

1. Click "+ Create Group"
2. Enter group details:
   - **Group Name**: What is this group for? (e.g., "Office Tea Gang", "Weekend Party Squad", "Lunch Buddies")
   - **Description** (optional): More context about the group
   - **Emoji**: Pick an emoji that represents the group
3. Click "Create Group"
4. You'll see your group code (6 characters) - share this with your group!

#### Join a Group
If someone already created a group:

1. Click "Join Group"
2. Enter the 6-character code they share with you
3. Click "Join Group"
4. Done! You're now part of the group

## Managing Payment Turns

### View Current Turn
On the group page, you'll see a big highlighted section showing whose turn it is to pay.

- The person's name is displayed with the group emoji
- In **Fair Mode**: Based on payment history (who has paid least)
- In **Random Mode**: Random selection (for fun!)

### Mark as Paid
When someone pays:

1. Click "Mark as Paid"
2. (Optional) Add a description of what was paid for:
   - "Tea round"
   - "Party drinks"
   - "Lunch order"
   - "Coffee and snacks"
3. Click "Confirm"
4. The payment is logged and the next payer is calculated

### Toggle Between Modes

**Fair Mode** (Default)
- Picks the member who has paid the least number of times
- If tied, picks the one who paid least recently
- Best for regular, fair rotations

**Random Mode**
- Picks anyone randomly
- Great for fun, casual scenarios
- Use the toggle switch to switch modes

## Understanding the Dashboard

### Members List
Shows all group members with how many times they've paid:
- Members sorted by payment count (lowest first)
- Badge shows payment count
- Lowest payer appears at the top

### Payment History
View all past payments:
- **Who**: The person who paid
- **Date**: When they paid
- **Description**: What the payment was for (if provided)
- Sorted by most recent first

### Group Info Card
Right sidebar shows:
- Group name and emoji
- Total members count
- Total payments count
- **Group Code**: Share this with others to join
  - Click "Copy" to copy the code to clipboard
  - Valid for 6 characters

## Features Explained

### Fair Turn Algorithm
The app tracks payment history to ensure fairness:

1. **Count Method**: How many times has each person paid?
2. **Selection**: Pick the person with the lowest count
3. **Tie-breaker**: If multiple people have the same count, pick the one who paid longest ago
4. **First-timers**: Members who haven't paid are prioritized

Example:
- Alice: 3 payments
- Bob: 2 payments
- Carol: 2 payments (last paid 2 weeks ago)
- Diana: 0 payments

→ **Diana's turn first** (hasn't paid yet)
→ **Carol's turn next** (paid 2 weeks ago, same count as Bob)
→ **Bob** (paid more recently than Carol)
→ **Alice** (has paid the most)

### Random Mode
Sometimes you just want chaos! Toggle Random Mode when:
- You want to gamble on who pays
- The group wants a fun, unpredictable round
- Everyone agreed to leave it to chance

### Group Codes
- Every group gets a unique 6-character code
- Share this code with anyone who should join
- They enter it to join - no complex invitations needed
- Codes are permanent for the group

## Tips & Tricks

### For Group Creators
- Share the group code early so everyone can join
- Set a fun emoji that matches your group's purpose
- Add a helpful description so members know what it's for

### For Everyone
- **Add Descriptions**: Makes it clear what each payment was for
- **Share Groups**: You can be in multiple groups (work team, friend group, family)
- **Track Fairness**: Check the member list to see who's paid most/least
- **Switch Modes**: Use Random Mode when fair mode gets boring!

## Troubleshooting

### My Data Disappeared
- Turnly stores data locally on your device/browser
- Clearing browser data will remove Turnly data
- Try logging back in (your name might be remembered)

### Group Code Doesn't Work
- Make sure you're entering the exact code (case doesn't matter)
- Ask the group creator to verify they gave you the right code
- Some characters look similar (0 vs O, 1 vs l) - double-check

### I Want to Leave a Group
- Go to the group page
- Scroll to the bottom of the right sidebar
- Click "Leave Group"
- You can rejoin later with the code

### I Forgot Someone's Name
- Check the Members list in the group
- All members are shown with how many times they've paid

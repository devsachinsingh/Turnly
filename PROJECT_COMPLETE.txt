Framework Stack:
  • Next.js 16 (App Router)
  • React 19.2 with Hooks
  • TypeScript (fully typed)
  • Tailwind CSS
  • shadcn/ui components

Storage:
  • Browser localStorage (no backend)
  • JSON serialization
  • Type-safe abstraction layer

Algorithms:
  • Fair Turn: O(n + h) complexity
  • Random Turn: O(1) random selection
  • Group Code: 6-char alphanumeric (2.8B combinations)

Data Model:
  • User: { id, name }
  • Group: { id, name, description, emoji, code, members, paymentHistory }
  • Member: { id, name, joinedDate }
  • PaymentRecord: { memberId, memberName, date, description }
